城市意象互動比較｜GitHub Pages 靜態版

上傳方式
1. 解壓 ZIP。
2. 將 landwalk-site 資料夾內的 index.html、style.css、app.js、兩個 JSON 和本說明檔，上傳到 GitHub repo 根目錄。
3. 在 GitHub Pages 選 main 分支與 / (root)。請確認 repo 根目錄直接看得到 index.html。

本版保留三城比較、五元素切換、城市自評與診斷摘要複製功能。所有路徑均為相對路徑，可部署到 /landwalk/ 等子目錄。自評是閱讀練習，不是原書量表；所有輸入和分數都只在瀏覽器中處理。

來源：先前建立的「城市意象互動比較」公開網站之頁面內容與樣式，2026-10-13 轉為無伺服器的靜態版本。互動腳本為重新實作。版面與互動資料已做靜態結構檢查；目前執行環境無法啟動本機瀏覽器或本機測試伺服器，因此沒有宣稱完成實際 GitHub Pages 線上測試。
